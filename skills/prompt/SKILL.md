## Objetivo
Criar prompts claros, completos e eficazes para interacao com modelos de linguagem e agentes de IA.

## Quando ativar
- Usuario precisa gerar prompt para outra ferramenta/agente
- Criacao de instrucoes de sistema ou skills
- Otimizacao de prompt existente
- Geracao de prompt para Lovable, Codex ou Claude

## Procedimento
1. Entenda o objetivo do prompt
2. Defina persona/papel do modelo
3. Especifique contexto relevante
4. Liste instrucoes explicitas e restricoes
5. Inclua exemplos de entrada/saida quando util
6. Defina formato de resposta esperado
7. Revise para clareza e completude

## Criterios de conclusao
- Prompt gerado com todos os elementos necessarios
- Instrucoes nao ambiguas
- Formato de saida definido
- Testado ou revisado quanto a eficacia

## Erros comuns
- Instrucoes vagas ou contraditorias
- Falta de contexto essencial
- Nao especificar formato de saida
- Prompt muito longo sem estrutura
